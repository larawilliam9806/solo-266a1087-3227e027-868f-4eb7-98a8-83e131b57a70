# 旧报纸价目表录入

上传单页 OCR CSV（框号、文字、矩形坐标），在页面上对照文字框划定行线与
**品名 / 规格 / 批发价** 三列，逐个人工核对跨格或出界的框，最后下载三列 CSV。

录入完成后的任务会挂到某一期的指定页码上；在**两期对照**页面选择两期，
即可按品名和规格并排查看两期已核完页面的全部报价，并标明页码和表内行号。

## 规则

- **自动归位**：文字框完整落在一格内（四边都在格线内，贴线也算）时自动进入该格。
- **待核**：跨格、出界、与任何格子都没有面积重叠的框进入待核。人工只能：
  - 选择一个与该框**有面积重叠**的格子（下拉框只列出这些格），或
  - 排除该框（文字为空或与价目表无关的内容）。
- **决定沿用**：每个待核框的人工决定会记下当时与之相交的全部格子坐标。
  改格线后重新计算，只有相交格集合完全相同（相交格及其边界都未变）的决定才沿用；
  其余自动回到待核（状态“待重新确认”）。改一条与某框无关的行线不会影响该框的决定。
- **格线无效**：竖线必须恰好 4 条、横线至少 2 条。提交无效格线会被拒绝，
  原来保存的布局与归位结果保持不变。
- **导出**：没有待核框且格线有效时才可下载。同格内的文字按**从上到下**、
  同一高度内**从左到右**拼接。输出 UTF-8 BOM 的 `品名,规格,批发价` CSV。

## 期号、页码与两期对照

- 首页登记**期号**和该期价目表**总页数**；总页数可以修正，但不能少到低于已挂页的最大页码。
- 在任务页或期号页把已有任务挂到指定页码；可补页、可换页。
  - **每个页码只挂一个任务**：挂到已有任务的页码即换页，原任务退回“未挂页”。
  - **每个任务只挂一处**：换页、换期会自动解除原来的挂载。
  - 挂页/换页失败（页码超出总页数、期号不存在等）时保留原结果，不做任何改动。
- 对照页面选择两期，按 **品名 + 规格** 并列显示两侧已核完页面的全部报价，
  每条报价都标明**页码**和**表内行号**。同一报价出现多次时合并显示全部出处。
- 某期找不到对应商品时，**只有该期页码齐全、且所有页都达到现有导出条件**
  （格线有效、没有待核框），才标为**未刊登**；否则标为**待核**，
  并列出**缺页**和**未核完的页**。两侧分别按各自的完整度判断。
- 未核完的页面不参与报价对照，避免半成品价格看起来像已刊登。
- 改格线、处理文字框、换页或删除任务后，缓存立刻失效，失效的报价从对照中撤下。
- 重复查询不会重新归位未改动的页：每份任务的导出结果按保存版本缓存，
  任务一有改动即作废重算；报价、缺页和待核页来自同一份快照。

## 本地运行

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
DATABASE=./pricing.sqlite3 flask --app run:app run --port 5000
# 或 python run.py
```

打开 <http://localhost:5000>。

## Docker Compose

```bash
docker compose up --build
```

- 默认映射 `5000:5000`，可用 `PORT=8080 docker compose up` 改端口。
- SQLite 数据保存在命名卷 `pricing-data`（容器内 `/data/pricing.sqlite3`）。
- 生产环境请设置 `SECRET_KEY`。

## OCR CSV 格式

表头可用中文或英文，列顺序不限：

```csv
框号,文字,x1,y1,x2,y2
1,白砂糖,120,80,260,110
2,一级,270,80,360,110
```

支持的其他写法：

| 形式 | 示例 |
| --- | --- |
| 矩形坐标单列 | `框号,文字,矩形坐标` → `1,白砂糖,"120,80,260,110"` |
| 英文表头 | `box,text,left,top,right,bottom` |
| 左上角 + 宽高 | `框号,文字,x,y,宽,高` |
| 无表头 | 按 `框号,文字,x1,y1,x2,y2` 读取 |

编码自动识别 UTF-8（含 BOM）、GB18030、Big5；分隔符支持逗号、分号、制表符。
单行坐标损坏会跳过并提示，不会导致整页失败。

## 代码结构

```
pricing/
  app.py        Flask 路由、状态组装、JSON API、导出、期号/页码、对照
  layout.py     纯逻辑：格线网格、归位判定、决定有效性、阅读顺序、行拼接、两期对照
  csvparse.py   OCR CSV 解析（多表头/多编码/单列坐标）
  db.py         SQLite 读写（期号、挂页、导出缓存）
  schema.sql    表结构
  templates/    任务列表 / 编辑页 / 期号页 / 对照页 / 错误页
  static/       页面样式与前端交互（SVG 画框、拖拽格线、归位操作）
sample/         示例 OCR CSV
tests/          Python 单元/集成测试 + jsdom 页面测试
```
